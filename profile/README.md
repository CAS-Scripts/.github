# CAS Scripts

**RedM scripts for VORP Core and RSG Core roleplay servers**, made by Code After S\*x. Character creation, inventory, HUD, admin tools, jobs, economy and full maps, most of them with a live demo you can try in the browser before you buy.

**[Store](https://codeaftersex.com/scripts)** | **[Free maps](https://codeaftersex.com/maps)** | **[Documentation](https://code-after-sex.gitbook.io/script-documentation/)** | **[Discord](https://discord.gg/codeaftersex)** | **[YouTube](https://www.youtube.com/@codeaftersex)**

## Free and open source

Clone them, read them, run them on your server.

| Resource | What it does | Framework |
| --- | --- | --- |
| [cas-artheist](https://github.com/CAS-Scripts/cas-artheist) | Art heist: steal statues and paintings, sell them to NPC dealers, haul them by wagon | VORP / RSG |
| [cas-armour](https://github.com/CAS-Scripts/cas-armour) | Slot based equipment and armour with damage reduction, wear and set bonuses | VORP / RSG |
| [cas_fwlibs](https://github.com/CAS-Scripts/cas_fwlibs) | Small framework bridge (money, items, jobs, players) used by our free scripts | VORP / RSG / TPZ |
| [cas-charcreator-companions](https://github.com/CAS-Scripts/cas-charcreator-companions) | vorp_character shim and rsg-appearance stub for CAS Character Creator | VORP / RSG |
